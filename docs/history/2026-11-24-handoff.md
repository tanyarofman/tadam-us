## How every article is made (keep doing it this way)
1. **Research:** start from the saved data in `docs/seo/data/*-us-2026-11-24.csv` (questions, SERPs, volumes). Run `python3 tools/seo/research.py questions --market us --kw "..."` only where data is thin. Check the balance before and after (`GET /v3/appendix/user_data`) and log the spend in `docs/seo/status.md`.
2. **Headings first:** show Tanya the H1, the question H2s, the table and the FAQ. Write only after she approves.
3. **Write** following the CLAUDE.md rules:
   - each H2 is a question with a 2-sentence capsule;
   - one table and 4 FAQ items;
   - 3 to 5 internal links, only to articles that exist;
   - sources linked inline and logged in `docs/seo/sources.md`;
   - one labeled example scenario and the hidden marker;
   - one honest Tadam section at the end;
   - no prices, celebrities, team names or TV-show content.
4. **Verify:**
   - `python3 tools/seo/check_articles.py <slug> ...`;
   - `npm run check` and `npm run build`;
   - `npx astro preview --port 4329` and `node tools/seo/check_mobile.mjs <slug> ...` (390px, no overflow, tables fit).
5. **PR:** a `feat/…` branch and a table of articles with deploy-preview links (`deploy-preview-<n>--tadam-us.netlify.app/blog/<slug>/`). Update `status.md` and `sources.md`. Never merge until Tanya says so.

Two things learned in wave 1:
- **Tables:** a 5-column table at 390px only fits if every cell's longest word is short. Avoid long hyphenated words, and use "Mid" instead of "Medium".
- **Capsule check:** a question mark inside the capsule counts as a sentence end. Write quoted questions without "?" in the capsule.
