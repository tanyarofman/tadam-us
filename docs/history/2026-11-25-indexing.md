# 2026-11-25: Indexing all pages, and IndexNow

## What happened
- Google's Request indexing quota (about 10 a day) ran out again. URL inspection of `/blog/hanukkah-games/` showed "No referring sitemaps detected": Search Console had last read the sitemap on 2026-11-24, when it listed 22 pages. The live sitemap has 43.
- Tanya resubmitted `https://tadamevents.com/sitemap-index.xml` in Search Console. Google re-reads it within a day or two.
- Bing Webmaster Tools: Tanya pasted all 43 sitemap addresses into URL Submission (quota 100 a day), and added `sitemap-0.xml` directly, because Bing had found only 1 address through the sitemap index.

## Decided
- Tanya asked for IndexNow, so Bing hears about new and changed pages automatically after each production deploy. Built as a Netlify event function (`netlify/functions/deploy-succeeded.mjs`, logic in `netlify/lib/indexnow.mjs`). It sends only pages whose HTML changed since the last production deploy (fingerprints kept in Netlify Blobs), plus removed pages. Deploy previews are skipped. Tested: two builds without changes produce identical HTML, so a deploy with no page changes sends nothing.
- No "instant Google indexing" services: they use Google's Indexing API, which Google allows only for job posts and livestreams.
